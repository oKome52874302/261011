# MacroLog — 筋トレ・ダイエット向け食事記録アプリ

スマホのブラウザで動く、PFC（たんぱく質・脂質・炭水化物）管理に特化した食事記録Webアプリです。
ビルド不要・サーバー不要。データは端末のブラウザ（localStorage）に保存されます。

## 使い方
`index.html` をブラウザで開くだけ。GitHub Pages 等で公開すればスマホのホーム画面に追加して使えます。

## 機能
- **目標の自動計算**：性別・年齢・身長・体重・活動量・目的（減量／維持／増量）から基礎代謝・TDEE・目標kcal・PFCを算出（手動上書きも可）
- **食事記録**：朝・昼・夕・間食ごとに記録。内蔵食品（約30品）から「1個」「茶碗1杯」などの単位 or グラムで追加
- **マイ食品**：パッケージの栄養表示を手入力して保存 → 次回から検索に出る
- **最近使った食品が上に表示**、**前日の食事をコピー**（毎日同じ食事の人向け）
- **たんぱく質の残り**を「鶏むね肉◯g／プロテイン◯杯」に換算して表示
- **体重記録**：推移グラフ＋7日移動平均、週あたりの変化率から「ペースが速い/遅い」を目的別にアドバイス
- データのJSON書き出し／読み込み

## 計算ロジック
- 基礎代謝：Mifflin-St Jeor式
- 目標kcal：減量 TDEE×0.8／維持 ×1.0／増量 ×1.1
- たんぱく質：体重×（減量2.2／維持1.8／増量2.0）g、脂質：総kcalの25%、残りを炭水化物

## 注意
内蔵食品の栄養値は日本食品標準成分表（八訂）等を参考にした**概算値**です。市販品は商品の表示を優先してください。
